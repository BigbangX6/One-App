One App

Règles de confidentialité

Dernière mise à jour : 8 octobre 2026

En bref
  • One App n'a pas de serveur : vos applications et vos documents sont enregistrés dans votre Google Drive.
  • One App n'accède qu'aux fichiers qu'elle a créés ou que vous lui avez ouverts, jamais au reste de votre Drive.
  • Aucune donnée n'est vendue, ni utilisée pour de la publicité, ni envoyée à un serveur de One App.

1. Ce qu'est One App

One App (bigbangx6.github.io/One-App) est une application web qui permet de créer, d'ouvrir et de partager de petites applications (fichiers .oneapp) et leurs documents (fichiers .onefile). Elle fonctionne entièrement dans votre navigateur et utilise votre compte Google Drive comme espace de stockage.

2. Données Google auxquelles One App accède

Lors de la connexion, Google vous demande d'autoriser One App. L'autorisation demandée est limitée (drive.file) :

  • Les fichiers créés par One App dans votre Drive : le dossier « One App », vos applications, vos documents, le raccourci « #Ouvrir One App.pdf ».
  • Les fichiers que vous ouvrez avec One App, par exemple un document qu'une autre personne vous a partagé et que vous choisissez d'ajouter via la fenêtre de sélection Google.
  • Votre nom et votre adresse e-mail Google, uniquement pour les afficher dans One App et pour réserver les données gardées sur l'appareil à votre compte.

One App ne peut pas voir, lire ni modifier les autres fichiers de votre Drive.

3. Utilisation de ces données

Ces données servent uniquement à faire fonctionner One App : afficher vos applications et documents, les ouvrir, enregistrer vos modifications, gérer l'historique des versions et le partage que vous déclenchez.

L'utilisation et le transfert vers toute autre application des informations reçues des API Google respectent les règles relatives aux données utilisateur des services API Google, y compris les exigences d'utilisation limitée (Limited Use).

4. Où sont stockées vos données

  • Dans votre Google Drive : vos applications et vos documents. Ils sont soumis aux règles de confidentialité de Google.
  • Sur votre appareil, dans le stockage de votre navigateur : le jeton de connexion Google (valable environ une heure), une copie des applications et des documents que vous avez ouverts (pour l'ouverture rapide et l'utilisation hors-ligne), et vos modifications pas encore envoyées à Drive.

Les données gardées sur l'appareil sont effacées lorsque vous vous déconnectez, ainsi que lorsqu'un autre compte Google se connecte sur le même appareil.

5. Partage

  • Documents : ils restent privés tant que vous ne choisissez pas de les partager. Le partage (lecture ou modification par toute personne disposant du lien) n'est appliqué que lorsque vous le validez.
  • Applications : le code d'une application que vous créez est rendu lisible par toute personne disposant de son lien, afin que les personnes avec qui vous partagez un document puissent l'ouvrir. Ce code ne contient pas vos documents ; n'y écrivez pas d'informations personnelles.

6. Services tiers

  • Google (connexion, Google Drive, fenêtre de sélection de fichiers) : règles de confidentialité de Google.
  • GitHub Pages, qui héberge One App : comme tout hébergeur, GitHub peut enregistrer des informations techniques de connexion (adresse IP, navigateur). Déclaration de confidentialité de GitHub.
  • Applications créées par les utilisateurs : elles s'exécutent dans un espace isolé et peuvent charger des bibliothèques externes choisies par leur auteur.

Le QR code d'un lien de partage est créé directement sur votre appareil, sans passer par un service extérieur. One App n'utilise ni cookies publicitaires, ni outil de mesure d'audience.

7. Vos choix et vos droits

  • Supprimer vos données : supprimez le dossier « One App » dans votre Google Drive.
  • Retirer l'accès de One App à votre compte Google : myaccount.google.com/permissions.
  • Effacer les données de l'appareil : déconnectez-vous de One App.

One App ne conservant aucune donnée sur un serveur, les données vous concernant se trouvent dans votre Google Drive et sur vos appareils, où vous en gardez le contrôle.

8. Contact

Pour toute question sur ces règles : github.com/BigbangX6/One-App/issues.

9. Modifications

Ces règles peuvent évoluer avec One App. La date de dernière mise à jour figure en haut de cette page.
